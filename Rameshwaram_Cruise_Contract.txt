1. SCOPE OF SERVICES & DELIVERABLES
------------------------------------------------------------------------
The Developer shall design, develop, test, and deploy a web-based ticket 
reservation and inventory management application for the Client. The specific 
scope of deliverables includes:

1.1 Booking Funnel & Ticketing System
* Interactive, mobile-responsive seat selection layout (60 seats matching 
  vessel deck architecture R1..R10 x 6 layout).
* Real-time seat lock mechanism (7-minute hold) to prevent double-booking.
* Billing Address collection on checkout page.
* Automated dynamic PDF e-ticket generation and delivery to the customer's 
  email via SMTP gateway.
* Boarding credential checks for passengers.

1.2 Administrative Staff Dashboard
* Batch Schedule Generator: Interface to create daily slots in bulk over 
  custom date ranges with specific time slots.
* Dynamic Surge Pricing Control: Quick interface to adjust seat prices for 
  festival slots (e.g. surge up to Rs. 5,000) directly, without accessing 
  Django's admin backend.
* Chronological Bookings Manager: Clean list views of active reservations 
  sorted by date/month/year, omitting redundant layout fields.
* Staff 2-Factor Authentication (2FA): OTP verification step for staff log-ins 
  to prevent unauthorized admin access.

1.3 Production Server Deployment (VPS Setup)
* Installation and configuration of Gunicorn WSGI gateway processes and 
  Nginx reverse proxy blocks on the Client's Linux Ubuntu VPS.
* Configuration of secure SSL (HTTPS) encryption certificates via Let's Encrypt.
* Database setup (PostgreSQL) and automated background cron tasks to release 
  expired reservations.
